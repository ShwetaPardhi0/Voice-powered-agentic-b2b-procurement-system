User Review Required
PostgreSQL Credentials: We will default 
.env
 properties to target port 5432 and standard credentials. We will create a 
.env
 template that you can update to point to your credentials on the local Windows service postgresql-x64-17.
Embedding Model: Default to text-embedding-3-small (1536 dimensions) using openai API client. If OPENAI_API_KEY is not provided in 
.env
, we run a deterministic unit-vector simulator of 1536 float elements so that all seeding, indexing, and retrieve flows remain fully runnable out-of-the-box.
Libraries: Ingestion parses PDFs using pypdf.
Proposed Changes
🗄️ Component 1: Database Setup (procurement-ai/database/)
[NEW] 
connection.py
Encapsulates connection configurations and exposes a psycopg2 pooling/connection context manager.
[MODIFY] 
schema.sql
Define:
inventory (sku PRIMARY KEY, name, stock_level, reorder_threshold, unit)
vendors (id PRIMARY KEY, name, category, pricing JSONB, catalog_text)
product_catalog (id, sku, name, description, vendor_id, embedding vector(1536))
documents
 (id, source, title, chunk_text, chunk_index, embedding vector(1536))
IVFFlat Indexes (vector_cosine_ops) on both embeddings.
[NEW] 
init_db.py
Seeds the database by reading from data/products.json and 
data/vendors.json
, processes their texts, produces 1536-dimensional embeddings, and writes to inventory, vendors, and product_catalog.
📖 Component 2: RAG Pipeline (procurement-ai/rag/)
[NEW] 
ingest.py
Iterates through all .pdf documents in data/contracts/.
Extracts pdf page text, builds chunks (e.g. 500-1000 characters), computes embeddings, and stores in the 
documents
 table.
[NEW] 
retrieve.py
Exposes 
search_catalog(query: str, limit: int)
 and 
search_documents(query: str, limit: int)
.
Generates query embedding and runs pgvector cosine similarity search (<=>) over indexed columns.
🤖 Component 3: Agent Wrap (procurement-ai/agents/)
[MODIFY] 
rag_agent.py
References rag/retrieve.py functions to expose inventory catalog matching and contract reading methods to the LangGraph supervisor.
📝 Component 4: Test & Seed Data (procurement-ai/data/)
[NEW] 
products.json
Setup M8 screws, steel plates, and aluminum ingots data.
[NEW] 
vendors.json
Setup details for Steel Dynamics, Global Alloys, and Hardware Hub.
[NEW] 
contracts/mehta_traders.pdf
 & 
contracts/supplier_catalog.pdf
PDF contracts containing specific logictic details and terms (generated automatically as clean text PDFs during testing).


# Verification Plan

Spin up PostgreSQL locally (using the native postgresql-x64-17 service on port 5432).
Run database initialization and generate embeddings: python database/init_db.py
Run PDF ingestion: python rag/ingest.py
Run retrieval and query validations: python verify_flow.py
